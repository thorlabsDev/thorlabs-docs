title: "ThorEdge RPC"
description: "Connect to Solana JSON-RPC and WebSocket endpoints from one location URL."

ThorEdge gives you Solana JSON-RPC over HTTPS and subscriptions over WSS. Copy the complete URLs for one location from the dashboard; a successful first request returns a JSON-RPC result with a recent blockhash.

## Use ThorEdge when

Use ThorEdge for standard Solana RPC calls or WebSocket subscriptions. Supported account-query methods use the same URL and are routed through [FastGate](/products/fastgate-account-api).

Choose [Yellowstone gRPC](/products/yellowstone-grpc), or [Pulse Decoded Shreds](/products/pulse) after deployment confirmation, when you need a persistent data stream instead of request-response RPC.

## Connection contract

| Item                 | Value                                           |
| -------------------- | ----------------------------------------------- |
| Requests             | HTTPS, JSON-RPC 2.0                             |
| Subscriptions        | WSS                                             |
| Endpoint             | Complete location URL copied from the dashboard |
| Authentication       | Credential carried by the copied URL            |
| Credential scope     | Selected access, network, and location          |
| Optional restriction | One stable public IPv4 address                  |
| Live limits          | **Usage** and **Limits** in the dashboard       |

## Before you start

You need:

- An active pass or rental with an enabled network and location
- A token for that location
- `curl` and `jq` for the first request
- One stable public egress IPv4 if you want to restrict the token

## Copy your endpoints

<Steps>
  <Step title="Select your access">
    Open **Endpoints → Endpoints**, then select the pass or rental you want to
    use.
  </Step>
  <Step title="Choose a network and location">
    Select the network and an offered location for the access.
  </Step>
  <Step title="Create or select a token">
    Use a token for the selected location. You can optionally restrict it to one
    stable public IPv4 address.
  </Step>
  <Step title="Copy both secure URLs">
    Copy the complete `https://` RPC URL and `wss://` WebSocket URL. Do not
    assemble either URL yourself.
  </Step>
</Steps>

<Warning>
  The complete HTTPS and WSS URLs contain or resolve to authentication material.
  Store them as secrets and keep them out of browser bundles, logs, screenshots,
  and source control.
</Warning>

## Send your first request

Store the copied HTTPS URL in your environment, then request a recent blockhash:

```bash
export THORNODE_RPC_URL='<copied-https-url>'
set -o pipefail

curl --fail-with-body "$THORNODE_RPC_URL" \
  --header 'content-type: application/json' \
  --data '{"jsonrpc":"2.0","id":1,"method":"getLatestBlockhash"}' \
  | jq '{
      jsonrpc,
      id,
      hasBlockhash: (.result.value.blockhash | type == "string"),
      error: (.error // null)
    }'
```

Expected output:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "hasBlockhash": true,
  "error": null
}
```

`hasBlockhash: true` and `error: null` are the success signal. Configure your Solana WebSocket client with the complete `wss://` URL from the same location panel when you need subscriptions.

## Run in production

- Treat non-2xx HTTP responses and JSON-RPC `error` objects as failures.
- Retry only transient failures with bounded backoff and jitter.
- Recreate WebSocket subscriptions after reconnecting and reconcile state when gaps matter.
- Recopy a URL after its token is regenerated or revoked; other location tokens are unaffected.
- Read current throughput and concurrency values from **Usage** and **Limits**.

## Troubleshooting

| Symptom                   | Verify                                                                     | Expected result                                                | Action                                                       |
| ------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------ |
| Unauthorized or forbidden | Access, network, location, token, and optional IPv4 restriction            | One minimal RPC call returns a JSON-RPC result                 | Recopy the complete URL from the selected location           |
| Rate limited              | Current traffic against **Usage** and **Limits**                           | Traffic remains below the applicable live limit                | Reduce concurrency and retry transient failures with backoff |
| RPC works but WSS fails   | The copied URL starts with `wss://`; outbound WebSocket traffic is allowed | The secure connection opens and accepts a subscription request | Recopy the WSS URL and update network policy                 |
| A working URL stopped     | The token was regenerated, revoked, or its access expired                  | A current active token succeeds; the replaced value does not   | Create or select a current token and replace the URL         |
