---
title: "getBlockTime"
description: "Returns the estimated production time of a block."
---

Returns the estimated production time of a block.

## On ThorNode

Forwarded to the upstream node with a 10 s timeout and one retry on a transport error.  History is limited to the upstream's retained ledger; slots older than `getFirstAvailableBlock` return an error.

## Parameters

<ParamField body="slot" type="integer" required>
  Block slot number to retrieve the corresponding timestamp for.
</ParamField>

## Response

<ResponseField name="result" type="integer">
  Unix timestamp (seconds since the Unix epoch) when this specific Solana block was produced by a validator.
</ResponseField>

<RequestExample>
```bash cURL
curl --fail-with-body "$THORNODE_RPC_URL" \
  --header 'content-type: application/json' \
  --data '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "getBlockTime",
    "params": [
      439749081
    ]
  }'
```

```javascript Node.js
const body = {
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getBlockTime",
  "params": [
    439749081
  ]
};

const response = await fetch(process.env.THORNODE_RPC_URL, {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify(body),
});
const { result, error } = await response.json();
console.log(result ?? error);
```
</RequestExample>

```json Response

```
</ResponseExample>
