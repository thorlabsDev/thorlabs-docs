Get the max slot seen from retransmit stage where a validator is currently retransmitting data shreds to help repair other nodes

## On ThorNode

Forwarded to the upstream node with a 10 s timeout and one retry on a transport error.

## Parameters

This method takes no parameters.

## Response

<ResponseField name="result" type="integer">
  Highest Solana slot number where this validator node is currently retransmitting data shreds to help repair other nodes.
</ResponseField>

<RequestExample>
```bash cURL
curl --fail-with-body "$THORNODE_RPC_URL" \
  --header 'content-type: application/json' \
  --data '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "getMaxRetransmitSlot"
  }'
```

```javascript Node.js
const body = {
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getMaxRetransmitSlot"
};

const response = await fetch(process.env.THORNODE_RPC_URL, {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify(body),
});
const { result, error } = await response.json();
console.log(result ?? error);
```
</RequestExample>

<ResponseExample>
```json Response
{
  "jsonrpc": "2.0",
  "result": 439749136,
  "id": 1
}
```
</ResponseExample>
