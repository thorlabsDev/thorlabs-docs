Returns the genesis hash, the unique identifier for a Solana cluster (mainnet, devnet, or testnet).

## On ThorNode

Forwarded to the upstream node with a 10 s timeout and one retry on a transport error.

## Parameters

This method takes no parameters.

## Response

<ResponseField name="result" type="string">
  Unique genesis hash (base-58 encoded) that cryptographically identifies this specific chain network (different for mainnet, testnet, devnet).
</ResponseField>

<RequestExample>
```bash cURL
curl --fail-with-body "$THORNODE_RPC_URL" \
  --header 'content-type: application/json' \
  --data '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "getGenesisHash"
  }'
```

```javascript Node.js
const body = {
  "jsonrpc": "2.0",
  "id": 1,
  "method": "getGenesisHash"
};

const response = await fetch(process.env.THORNODE_RPC_URL, {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify(body),
});
const { result, error } = await response.json();
console.log(result ?? error);
```
</RequestExample>
