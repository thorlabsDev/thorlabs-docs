Send any method below as a JSON-RPC 2.0 `POST` to the complete ThorEdge URL. Standard methods keep the request and response shapes defined in the [Solana JSON-RPC reference](https://solana.com/docs/rpc/http); ThorEdge adds the [error codes, rate-limit headers, and limits](/api-reference/overview) described in the overview.

Method names are matched exactly and case-sensitively. A method not listed here is forwarded to the upstream node, which decides whether it exists.

## Example

```bash
curl --fail-with-body "$THORNODE_RPC_URL" \
  --header 'content-type: application/json' \
  --data '{"jsonrpc":"2.0","id":1,"method":"getSlot"}'
```

```json
{ "jsonrpc": "2.0", "result": 439745109, "id": 1 }
```

## Transactions

| Method | Shape | ThorEdge behavior |
| --- | --- | --- |
| `sendTransaction` | [Solana](https://solana.com/docs/rpc/http/sendtransaction) | Forwarded once, unchanged, with an 8 s timeout. ThorEdge never resubmits; a `502` means you decide whether to rebuild and resend. Counts against the TPS cap. |
| `simulateTransaction` | [Solana](https://solana.com/docs/rpc/http/simulatetransaction) | Standard read; 10 s timeout. |
