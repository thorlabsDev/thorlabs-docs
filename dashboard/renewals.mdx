---
title: "Renew an owned pass"
description: "Extend an eligible owned pass by 1, 3, 6, or 12 months and verify the new expiration."
---

Use **Renew** to extend one or more eligible owned passes. Renewal is complete when the dashboard shows **Renewal Complete** and a new expiration for each selected pass.

Rentals, Gold passes, and Honorary passes are excluded from this flow.

## Check eligibility

| Access              | Renewal behavior                                             |
| ------------------- | ------------------------------------------------------------ |
| Eligible owned pass | Selectable under **Renew → Renew**                           |
| Rental              | Continues until its displayed expiration; not renewable here |
| Gold pass           | Not offered in the standard renewal flow                     |
| Honorary pass       | Not offered in the standard renewal flow                     |

The current dashboard state determines whether an owned pass is selectable. Review its displayed expiration and status before payment.

## Before you renew

You need:

- The intended Discord account
- The pass's owning address registered under **Wallets**
- A registered Solana wallet connected for payment
- Enough of the payment asset shown in the current order summary
- A small SOL balance for Solana transaction and account-creation fees

## Renew one or more passes

<Steps>
  <Step title="Open the renewal flow">
    Choose **Renew** in the sidebar, then keep the **Renew** tab selected. Under
    **Choose an action**, select **Renew**.
  </Step>
  <Step title="Select eligible passes">
    Under **Select passes**, choose the owned passes you want to extend. Gold,
    Honorary, and rental access cannot be selected for renewal.
  </Step>
  <Step title="Choose the renewal term">
    Under **Renewal term**, select **1 month**, **3 months**, **6 months**, or
    **12 months**.
  </Step>
  <Step title="Calculate the live amount">
    In **Order summary**, choose **Calculate price**. Review every selected
    pass, the term, line items, total, and displayed balance.
  </Step>
  <Step title="Submit one payment">
    If needed, choose **Connect Wallet to Pay** and connect a registered wallet.
    In the wallet extension, verify the full paying address, asset or mint,
    destination, and amount. Then choose **Pay … USDC** and approve the
    transaction once.
  </Step>
  <Step title="Wait for completion">
    Keep **Processing Renewal** open until **Renewal Complete** lists the new
    expiration for each pass.
  </Step>
</Steps>

<Warning>
  Do not submit another payment while renewal is processing or after payment
  succeeded. If a pass update fails after payment, use **Retry Failed Passes**;
  the retry reuses the completed payment.
</Warning>

## Recover a partial result

The results view lists each selected pass separately. If payment completed but a pass update failed:

1. Save the transaction signature shown under **Transaction**.
2. Choose **Retry Failed Passes** when the action is available.
3. Confirm that the retry does not open a new wallet approval.
4. Check each pass for a completed result and new expiration.

If retry cannot complete, contact [ThorNode support](mailto:support@thornode.io) with the public wallet, transaction signature, affected pass identifier, and approximate time. Do not send another payment.

## If a pass is missing or unavailable

| Symptom                                         | Verify                                              | Expected result                                                       | Action                                                                            |
| ----------------------------------------------- | --------------------------------------------------- | --------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Owned pass is absent                            | Discord account and registered owner address        | The owner appears under **Verified wallets**                          | Register the owning wallet, then reload **Renew**                                 |
| Pass is visible but disabled                    | Pass type and live state                            | An eligible standard pass is selectable                               | Gold and Honorary passes remain excluded; follow the state shown for other passes |
| Only rentals are shown elsewhere                | **Your rentals** versus owned passes                | Rentals are not listed as renewable NFTs                              | Use the continuation option shown for that rental; rentals do not use **Renew**   |
| Wallet cannot pay                               | Connected address, registration, asset, and balance | The connected address is registered and can cover the displayed total | Correct the prerequisite and recalculate before signing                           |
| Payment completed but expiration did not update | Per-pass result and transaction signature           | The pass reaches a completed result with a new expiration             | Use **Retry Failed Passes** or contact support; do not repay                      |
